# Security reporting

This repository contains a professional profile and its release-check tooling.
It is not a clinical application. Only the current default branch is maintained.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Ledbetter117/Ledbetter117/security/advisories/new).
Do not post credentials, private identifying information or exploit details in
public issues. Describe the affected revision, impact and a minimal synthetic
reproduction. Acknowledgment and fixes are handled by the maintainer; no response
time or bug-bounty commitment is implied.
